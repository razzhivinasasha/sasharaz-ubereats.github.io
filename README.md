# :hamburger: Uber Eats Landing Page

Профессиональный двухстраничный адаптивный лендинг сервиса доставки еды **Uber Eats**. Проект представляет собой точную современную верстку основных экранов сервиса, включая главную страницу со списками ресторанов, страницу конкретного заведения и модальное окно авторизации.

## :hammer_and_wrench: Стек технологий и инструменты:

*   **HTML5** — семантическая разметка.
*   **CSS3** — современные методы раскладки и стилизации:
    *   **Flexbox** — для линейных компонентов (навигационное меню, карточки, элементы выравнивания).
    *   **CSS Grid** — для построения сложных сеток основных секций.
    *   **Шрифты** — подключение сторонних шрифтов для соответствия дизайн-макету.
*  **@media** — Сайт автоматически подстраивает внешний вид страницы под размер экрана (телефон, планшет или компьютер).
* **Модальные окна:** Реализовано интерфейсное окно «Вход в аккаунт» с затемнением заднего фона (overlay).

## :rocket: О проекте

**Uber Eats** — это современный двухстраничный адаптивный веб-сайт сервиса доставки еды, разработанный для быстрого поиска ресторанов и удобного заказа блюд онлайн. 

Проект создан с использованием компонентного подхода к верстке и демонстрирует навыки построения сложных адаптивных интерфейсов и интерактивных элементов (таких как модальные окна и переключатели меню) на чистом CSS.

### 🗺️ Функционал и страницы проекта

#### 1. Главная страница (Каталог ресторанов — `index.html`)
* **Глобальная шапка (Header):** Фирменная панель навигации с логотипом бренда, поисковой строкой по ресторанам и кнопкой авторизации.
* **Каталог заведений:** Модульная Grid-сетка «Рестораны в Москве», отображающая карточки доступных партнеров. Каждая карточка содержит обложку, название, кулинарные теги, время доставки и ценовой сегмент.
* **Информационный подвал (Footer):** Комплексный многоколоночный футер с селектором выбора языка интерфейса, кнопками маркетплейсов (App Store, Google Play), внутренними ссылками для партнеров и блоком социальных сетей.

#### 2. Страница ресторана (Каталог ресторана — `index-2.html`)
* **Визуальный баннер:** Верхний брендированный экран конкретного заведения (на примере Трактира «Пушкин») с детальной информацией, рейтингом и временем приготовления.
* **Внутренняя навигация:** Горизонтальное меню быстрого переключения между категориями блюд (Закуски, Салаты, Супы, Горячие блюда, Десерты).
* **Сетка товаров:** Адаптивное меню блюд с детальным описанием состава, ценой в рублях и фотографиями позиций.

#### 3. Интерфейс авторизации (Модальное окно — `form.html`)
* **Всплывающее окно «Вход в аккаунт»:** Появляется поверх основного контента при клике на авторизацию.
* **Форма ввода:** Стилизованные поля для Email и Password, кастомный интерактивный чекбокс «Запомнить меня» и кнопка отправки данных.
* **Эффект Overlay:** Реализовано размытие и затемнение заднего плана для фиксации фокуса пользователя на форме.

#### 4. Адаптивность и Mobile-First решения
* Структура страниц полностью гибкая и перестраивается под любые разрешения экранов смартфонов и планшетов.
* На экранах срабатывает трансформация элементов: громоздкие ссылки скрываются в **Pure CSS «гамбургер-меню»** на базе Checkbox, а основной логотип подменяется оптимизированной мобильной мини-версией для экономии пространства.
